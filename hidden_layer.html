16 个神经元里只有 4 个被激活（n3、n6、n10、n12）。 其余 12 个的 z₁ 全为负，被 ReLU 压成了 0。

这就是 ReLU 的稀疏性：同一个样本只走其中一小部分通路，不同样本激活不同的神经元。

负值全部归零，正数原样通过。 这一步是整个网络唯一的非线性来源——如果去掉它， 两层矩阵乘法会合并成一个矩阵，模型立刻退化成实验 01 的线性模型。

副作用是「死神经元」：某个神经元如果长期只输出负值， 梯度恒为 0，它就再也学不动了。这个样本里 12 个神经元处于这种状态。

07

实现：这些全部来自 3 行代码

手写版（numpy）：

# 前向：12 维 → 16 维 → 1 维
z1 = X @ W1 + b1          # (m, 16)  这张表就是上面那个热力图
h1 = np.maximum(0.0, z1)  # (m, 16)  ReLU
pred = h1 @ W2 + b2       # (m, 1)   合成输出

框架版（PyTorch）等价写法：

self.fc1 = nn.Linear(12, 16)   # 对应 W1, b1
self.act = nn.ReLU()           # 对应 np.maximum(0, z1)
self.fc2 = nn.Linear(16, 1)    # 对应 W2, b2

所以「隐藏层」不是一个抽象概念：它就是一张 12×16 的权重表、一个 16 维偏置向量， 加一道 max(0, ·)。这个样本走完一遍，就是 12×16 = 192 次乘法加 16 次比较。
